# Milestone Feedback

This directory records hands-on prototype feedback and validation findings for major product milestones.

Use one file per milestone, for example:

```text
M1_FEEDBACK.md
M2_FEEDBACK.md
...
```

Copy `MILESTONE_FEEDBACK_TEMPLATE.md` when a milestone reaches prototype validation.

Feedback is project input, not automatic implementation authorization. Each material finding must be triaged as FIX BEFORE COMPLETE, CARRY FORWARD, FUTURE CONSIDERATION, or REJECTED / OUT OF SCOPE.
